`https://agentvolumes.org/problems/idempotency-conflict` identifies the `idempotency-conflict` Problem Details type in the closed Agent Volumes v0.1 portable problem set.

| Field       | Value                                                       |
| ----------- | ----------------------------------------------------------- |
| Type URI    | `https://agentvolumes.org/problems/idempotency-conflict`    |
| Slug        | `idempotency-conflict`                                      |
| HTTP status | `409`                                                       |
| Title       | `Idempotency conflict`                                      |
| Meaning     | A reused idempotency key conflicts with an earlier request. |

## Client guidance

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization, but the `type` URI identifies the portable problem category.
