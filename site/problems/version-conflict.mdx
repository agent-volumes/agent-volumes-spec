`https://agentvolumes.org/problems/version-conflict` identifies the `version-conflict` Problem Details type.

| Field       | Value                                                  |
| ----------- | ------------------------------------------------------ |
| Type URI    | `https://agentvolumes.org/problems/version-conflict`   |
| Slug        | `version-conflict`                                     |
| HTTP status | `409`                                                  |
| Title       | `Version conflict`                                     |
| Meaning     | The target version already exists or cannot be reused. |

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization.
