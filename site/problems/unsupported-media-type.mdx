`https://agentvolumes.org/problems/unsupported-media-type` identifies the `unsupported-media-type` Problem Details type.

| Field       | Value                                                      |
| ----------- | ---------------------------------------------------------- |
| Type URI    | `https://agentvolumes.org/problems/unsupported-media-type` |
| Slug        | `unsupported-media-type`                                   |
| HTTP status | `415`                                                      |
| Title       | `Unsupported media type`                                   |
| Meaning     | The submitted payload media type is not supported.         |

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization.
