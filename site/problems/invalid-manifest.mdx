`https://agentvolumes.org/problems/invalid-manifest` identifies the `invalid-manifest` Problem Details type in the closed Agent Volumes v0.1 portable problem set.

| Field       | Value                                                            |
| ----------- | ---------------------------------------------------------------- |
| Type URI    | `https://agentvolumes.org/problems/invalid-manifest`             |
| Slug        | `invalid-manifest`                                               |
| HTTP status | `400`                                                            |
| Title       | `Invalid manifest`                                               |
| Meaning     | A submitted volume.toml is structurally or semantically invalid. |

## Client guidance

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization, but the `type` URI identifies the portable problem category.
