`https://agentvolumes.org/problems/not-found` identifies the `not-found` Problem Details type.

| Field       | Value                                                                  |
| ----------- | ---------------------------------------------------------------------- |
| Type URI    | `https://agentvolumes.org/problems/not-found`                          |
| Slug        | `not-found`                                                            |
| HTTP status | `404`                                                                  |
| Title       | `Resource not found`                                                   |
| Meaning     | The requested resource does not exist or is not visible to the caller. |

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization.
