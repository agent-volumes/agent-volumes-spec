`https://agentvolumes.org/problems/payload-too-large` identifies the `payload-too-large` Problem Details type.

| Field       | Value                                                                                   |
| ----------- | --------------------------------------------------------------------------------------- |
| Type URI    | `https://agentvolumes.org/problems/payload-too-large`                                   |
| Slug        | `payload-too-large`                                                                     |
| HTTP status | `413`                                                                                   |
| Title       | `Payload too large`                                                                     |
| Meaning     | The submitted payload or declared upload size exceeds the bibliotheca's accepted limit. |
