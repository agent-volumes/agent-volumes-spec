`https://agentvolumes.org/build/manual/v0.1` identifies the manual build type URI used by Agent Volumes mapping fixtures.

This URI documents fixture and release-evidence context. It does not create a general build-system registry or a universal build profile.

## Current use

The v0.1 mapping sample uses the URI as a SLSA `buildType` value for a manually assembled fixture. Consumers should interpret it only in the context of the Agent Volumes v0.1 mapping artifacts.
