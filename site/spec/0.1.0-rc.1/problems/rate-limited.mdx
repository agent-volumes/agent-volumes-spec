`https://agentvolumes.org/problems/rate-limited` identifies the `rate-limited` Problem Details type in the closed Agent Volumes v0.1 portable problem set.

| Field       | Value                                            |
| ----------- | ------------------------------------------------ |
| Type URI    | `https://agentvolumes.org/problems/rate-limited` |
| Slug        | `rate-limited`                                   |
| HTTP status | `429`                                            |
| Title       | `Rate limited`                                   |
| Meaning     | The request was rate limited.                    |

## Client guidance

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization, but the `type` URI identifies the portable problem category.
