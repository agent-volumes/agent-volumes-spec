`https://agentvolumes.org/problems/invalid-archive` identifies the `invalid-archive` Problem Details type in the closed Agent Volumes v0.1 portable problem set.

| Field | Value |
| ----- | ----- |
| Type URI | `https://agentvolumes.org/problems/invalid-archive` |
| Slug | `invalid-archive` |
| HTTP status | `400` |
| Title | `Invalid archive` |
| Meaning | A submitted hosted archive violates the v0.1 archive transport profile. |

## Client guidance

Switch on the `type` URI when handling Agent Volumes Registry API errors. The human-readable `title` can vary by implementation or localization, but the `type` URI identifies the portable problem category.
