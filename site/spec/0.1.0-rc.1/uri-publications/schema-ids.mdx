Agent Volumes schema identifiers are versioned under the release subtree. Each `$id` URL is a durable identifier for the matching release artifact, not a mutable latest alias.

## URL pattern

```text
https://agentvolumes.org/spec/0.1.0-rc.1/schemas/<artifact>
```

- Do not rewrite released `$id` URLs for style.
- Keep schema pages auditable against the matching file in `schemas/`.
- Treat the prose specification as the final authority when interpreting structured artifacts.
