`https://agentvolumes.org/build/manual/v0.1` identifies the Agent Volumes v0.1 manual build type used in SLSA provenance examples and mapping fixtures.

This page describes the identifier itself. Release-specific documentation remains archived under `/spec/<version>/...`.

## Identifier

```text
https://agentvolumes.org/build/manual/v0.1
```

## Semantics

Use this build type when provenance describes a manually assembled or fixture-defined Agent Volumes release subject rather than an automated build platform.

The `v0.1` segment is the semantic identifier line. Patch releases can clarify this page without changing the identifier meaning. Incompatible changes require a new build type URI.

## Boundaries

- This identifier does not define a general build-system registry.
- It does not replace the SLSA provenance predicate type `https://slsa.dev/provenance/v1`.
- It does not imply that manually built releases are trusted without separate provenance, signature, and release-subject verification.
- It is interpreted in the context of the Agent Volumes mapping artifacts that define the `v0.1` line.
