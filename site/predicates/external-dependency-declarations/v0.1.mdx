`https://agentvolumes.org/predicates/external-dependency-declarations/v0.1` identifies the optional Agent Volumes in-toto predicate for declaration-plane external dependency metadata.

This page describes the predicate identifier itself. Release-specific schema and documentation artifacts remain archived under `/spec/<version>/...`.

## Identifier

```text
https://agentvolumes.org/predicates/external-dependency-declarations/v0.1
```

## Semantics

Use this predicate when external dependency declarations need to be carried outside SLSA provenance `subject`, `materials`, `resolvedDependencies`, `byproducts`, and `internalParameters`.

The predicate records declaration-only metadata. Do not treat it as scanner evidence, resolver output, installed-package evidence, or proof that a dependency was present in a build.

The `v0.1` segment is the predicate semantic line. Patch releases can clarify the release archive and schema publication without changing this identifier. Incompatible predicate semantics require a new predicate URI.
