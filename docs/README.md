# Agent Volumes Project Documentation

This directory collects project process, readiness, and operational policy
documents for the Agent Volumes specification repository.

These documents support contributors, maintainers, and alignment with OpenSSF
Best Practices. They do not replace the normative specification. The normative
source of truth remains [`../agent-volumes-spec.md`](../agent-volumes-spec.md),
with machine-readable companion artifacts under [`../schemas/`](../schemas/),
[`../openapi/`](../openapi/), and [`../conformance/`](../conformance/).

## Organization-wide policies

Agent Volumes uses organization-wide community health files from
[`agent-volumes/.github`](https://github.com/agent-volumes/.github). In
particular, the organization-wide
[`CONTRIBUTING.md`](https://github.com/agent-volumes/.github/blob/main/CONTRIBUTING.md),
[`SECURITY.md`](https://github.com/agent-volumes/.github/blob/main/SECURITY.md),
and
[`CODE_OF_CONDUCT.md`](https://github.com/agent-volumes/.github/blob/main/CODE_OF_CONDUCT.md)
apply to this repository.

Repository-local documents add spec-specific process details. They are not
separate governance documents unless they explicitly say so.
